# SECURITY.md

## Reporting a Vulnerability

We take the security of TaskUp MCP seriously. If you believe you have found a security vulnerability, please do NOT open a public issue. Instead, please report it privately.

### How to report

Please send an email to [security@alumnx.com](mailto:security@alumnx.com) with the following details:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

### What to expect

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary. We ask that you give us reasonable time to address the issue before making it public.

Thank you for helping keep TaskUp MCP safe!
